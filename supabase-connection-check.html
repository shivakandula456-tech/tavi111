This page checks whether the public website can reach your Supabase project and read the products table. It never asks for or displays a secret key.

What the result means

  • Connected and products table found: Supabase is reachable and the schema exists.
  • Table not found: the database migration has not been applied, or the table name differs.
  • Permission / RLS error: review the table policies in Supabase.
  • Network error: check internet access and the project URL.
This diagnostic does not modify your database or create any records.
